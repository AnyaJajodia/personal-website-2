# Approved visual design
Editorial minimalism: warm ivory, large elegant serif titles, clean sans-serif body, generous whitespace, subtle rules, one moving scribble. No glow, decorative gradients, excessive cards, 3D, or scroll hijacking.
Use exactly two font families. Suggested implementation: locally hosted Cormorant Garamond (headings) and Inter (body/navigation), with sensible fallbacks. These are implementation choices; the mockups establish the serif/sans relationship, not exact font files. Favor readable body text (18px desktop, 16–18px mobile), line height 1.5–1.65, max prose width 65 characters. Use fluid title sizes and never sacrifice legibility to fit.
Desktop content width approximately 1200–1320px with generous outer gutters. Collapse columns gracefully on mobile. Consistent small uppercase labels, ordinary readable body copy, square/simple image edges.
Homepage: full viewport hero; About with trajectory; Currently (two large Lynxster and AMNH features); Selected work (compact editorial rows); More placeholder; Contact. A slim sticky header settles as the large hero name recedes, without duplicating overlapping names.
Nav: Anya Jajodia. left; About / Work / More / Contact right. Home anchors scroll normally. Detail nav returns to homepage anchors. Work anchor starts at Currently and encompasses selected work. Maintain visible keyboard focus.
Lynxster: real logo, near-black/cyan opening, actual application screenshot, ivory case-study sections below. Shared typography and grid. Cyan line; recognizable personal navigation. Do not imitate app sidebar as website navigation.
AMNH: archival cream, real record/rig images when supplied, captioned diptych, restrained metadata, wing-like line flourish. Organization name and department as text; no invented official logo. Generated photos in mockup are placeholders only.
Other detail pages: neutral ivory/blue template with project title, subtitle, metadata, overview, contribution and reflection sections, relevant image/code/research space and next/previous navigation. Publications use contribution, abstract/overview and paper link as appropriate. Do not pad short entries.
Palette source: Lynxster colors sampled from screenshot pixels, not confirmed theme tokens. Portfolio/AMNH colors are chosen design values. Use colors.json as the current implementation values. Check contrast of links, captions and labels; decorative line colors do not need to serve as body text.
