# Inteli-lens
From footage to a working prototype.
A computer-vision experiment in identifying potentially intoxicated behavior.
Type: Independent project
Period: Start date to confirm–2027 [EDIT: no inferred start date]
Tools: Python · OpenCV · TensorFlow · PyQt5 · FFmpeg · SQLite
## Overview
Inteli-lens is a Python desktop prototype built to explore behavior detection in CCTV footage using OpenCV and TensorFlow CNNs.
## My contribution
I developed preprocessing and augmentation pipelines with NumPy and scikit-image to address lighting and camera-angle variation, built a PyQt5 GUI prototype, and integrated FFmpeg decoding and SQLite logging.
I validated the model on a labeled dataset and improved precision and recall. The résumé does not supply numerical values for those improvements.
## Scope
This was a prototype exploring a behavior-classification task. It was not a clinical assessment of intoxication. The desktop prototype was deployed; do not imply a production rollout.
